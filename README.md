# Tinapay

A food ordering website.

**Live site:** https://tinapay-shop.vercel.app

## Try it
- Log in with Google, or register with email and password
- Add items to the cart (total must be at least P30)
- Pay with the Stripe test card:
  - Card: 4242 4242 4242 4242
  - Expiry: any future date
  - CVC: any 3 digits

## Features
- Menu, cart and checkout
- Stripe payments (test mode)
- Google and email login
- Order history
- Admin pages for menu items and categories

## Built with
Next.js, MongoDB, NextAuth, Stripe, AWS S3, Tailwind CSS, Vercel
